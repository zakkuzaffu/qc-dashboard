# QC Dashboard Project

This project is a dynamic, data-driven Quality Control Dashboard that simulates a real-world manufacturing environment. It was built as the primary project for the CS 101 curriculum, demonstrating a full-stack skill set.

---

## 🎯 Project Goal

The goal was to build an application that could process raw material data (strength, density, etc.), apply logical quality checks, and display the final status (PASS/FAIL/WARNING) on a clean, professional web interface.

This project demonstrates the transition from a Metallurgy & Material Engineering background to a remote IT development career.

---

## 🛠️ Technology Stack

This project was built using the following technologies:

### Front-End (The Dashboard)
* **HTML5:** For the core structure and table.
* **CSS3:** For all styling, layout, and professional presentation.
* **JavaScript (ES6+):** For all client-side logic and DOM manipulation.

### Back-End (The Logic)
* **Python:** Used for data processing logic and server-side checks.
* **Pandas:** Used for advanced data analysis and filtering of QC data.
* **Git & GitHub:** Used for all version control and project management.

---

## 🚀 How to Run

1.  Clone this repository.
2.  Open `dashboard.html` in a browser using a Live Server.
3.  The `logic.js` file will automatically run, process the data, and populate the QC status table.
